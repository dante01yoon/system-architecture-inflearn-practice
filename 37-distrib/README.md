# distrib — 분산의 세 가지 기준

서점을 여러 대로 나눌지 정하는 세 가지 계산(`calc.py`): 용량(최고 부하 ÷ 서버 한 대), 가용성(복제본 중 하나만 살아 있으면 될 때), 거리(손님 위치별 왕복 시간).
숫자는 모두 설명을 위해 정한 가정이다: 최고 부하 초당 20,000건, 보통 서버 초당 2,000건, 가장 큰 서버 초당 8,000건, 서버 한 대 가용성 99.5%,
지역 사이 왕복 시간 표, 페이지 하나에 왕복 4번. 가용성 계산은 서버들이 서로 따로 고장 난다고 가정한다(실제로는 같은 건물·같은 배포로 함께 멈추기도 한다). 표준 라이브러리만 쓴다.

    python3 demo.py 1   # 용량
    python3 demo.py 2   # 가용성
    python3 demo.py 3   # 거리
    python3 -m unittest
    python3 solutions/copies.py   # 연습 문제 풀이
