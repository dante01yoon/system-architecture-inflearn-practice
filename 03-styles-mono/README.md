# 모놀리식 스타일 세 가지 예제 (파이썬 표준 라이브러리만)

같은 서점 기능(책 목록, 주문 + 쿠폰 할인)을 세 가지 스타일로 만든다.

| 폴더 | 스타일 | 나누는 기준 |
|---|---|---|
| `layered/` | 레이어드 | 기술 역할: 프레젠테이션 → 비즈니스 → 퍼시스턴스 → 데이터베이스 |
| `modular/` | 모듈러 모놀리스 | 도메인: catalog, ordering, coupons 모듈, 서로 공개 함수로만 |
| `microkernel/` | 마이크로커널 | 코어 + 플러그인: `plugins/` 폴더의 파일이 스스로 등록 |

```bash
python3 demo.py            # 같은 주문 금액, 지나간 층, 쿠폰 때문에 손댄 파일, 플러그인 빼기
python3 -m unittest        # 테스트
```

## 연습 문제

「선물 포장(2,000원 추가)」 기능을 세 스타일에 모두 붙이고, 손댄 파일 수를 세어 보세요.

풀이: 마이크로커널은 `solutions/gift_wrap.py`를 `microkernel/plugins/`에 복사하면 끝(코어 0개).
레이어드는 요청을 받는 층부터 규칙을 두는 비즈니스 층까지, 모듈러 모놀리스는 주문 모듈(또는 새 포장 모듈) 안에서 고친다.
