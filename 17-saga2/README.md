# saga2 — Saga ② 코레오그래피 대 오케스트레이션

같은 서점 주문 흐름(주문 → 결제 → 재고 → 배송)을 두 방식으로 돌린다. 한 프로세스 안의 이벤트 버스, 파이썬 표준 라이브러리만.

| 파일 | 역할 |
|---|---|
| `bus.py` | 토픽·구독자, 올라온 순서대로 배달하고 기록 |
| `shop.py` | 서비스 넷의 데이터와 로컬 트랜잭션(보상 포함) |
| `choreography.py` | 지휘자 없음. 서비스 4개가 서로의 이벤트를 구독 |
| `orchestration.py` | 주문 Saga가 `STEPS` 목록대로 커맨드를 보내고 답을 받는다. 피벗 뒤 단계는 다시 시도 |
| `demo.py` | 1 코레오그래피 성공 2 오케스트레이션 성공(배송 재시도) 3 결제 실패 두 방식 4 흐름을 읽는 곳 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/points.py   # 연습 문제 풀이

## 연습 문제
