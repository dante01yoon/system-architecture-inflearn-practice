# enough — 위험만큼만 설계하기

Fairbanks의 위험 주도 모델(위험을 찾고 순서 매기기 → 기법 고르고 쓰기 → 위험이 줄었는지 보기)을 서점 반짝 할인 전 위험 목록에 적용한다. 파이썬 표준 라이브러리만 쓴다.

| 파일 | 역할 |
|---|---|
| `risks.csv` | 위험 6개: 가능성·영향(1~5), 종류, 기법을 쓴 뒤 다시 매긴 가능성(after, 가정한 값) |
| `enough.py` | 점수(가능성 × 영향), 우선순위, 종류별 기법, 다시 매기기 |
| `demo.py` | 다섯 단계로 출력 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/check.py   # 연습 문제 풀이
