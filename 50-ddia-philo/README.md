# 스트리밍 시스템의 철학 예제: 로그 하나에서 파생 데이터 만들기 (파이썬 표준 라이브러리만)

온라인 서점의 일(책 등록·입고·판매)을 덧붙이기만 하는 로그 하나에 적고, 재고·검색 인덱스·일별 매출을 각자 따로 읽는 소비자로 만든다.

| 파일 | 역할 |
|---|---|
| `log.py` | `Log`(append·read, offset = 줄 번호), `View`(어디까지 읽었는지 기억하는 소비자), 뷰 넷(재고·검색·일별 매출·작가 인기) |
| `unique.py` | 아이디 유일성: 아이디로 파티션을 고르고, 파티션마다 한 번에 하나씩 처리해 먼저 온 요청이 이긴다. 같은 request_id는 한 번만 |
| `demo.py` | `1` 뷰 셋 따라잡기 → 새 뷰를 offset 0부터 · `2` 가입 요청 유일성 |
| `solutions/` | 연습 문제 풀이 |

```bash
python3 demo.py 1
python3 demo.py 2
python3 -m unittest
```

가격·판매 수는 예제용 숫자다. 실제 시스템에서는 로그가 Kafka 같은 분산 로그, 소비자가 스트림 처리 작업, 파티션 번호가 Kafka 파티션이다.

## 연습 문제

손님 한 명당 `WELCOME` 쿠폰은 한 번만 발급해야 한다. 쿠폰 요청을 어떤 키로 파티션에 나누면 될까요? 같은 요청을 다시 보낸 경우는 어떻게 할까요?
풀이: `python3 solutions/coupon.py`
