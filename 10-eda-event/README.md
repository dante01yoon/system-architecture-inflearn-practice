# eda-event — 「이벤트」의 뜻 비교하기

서점 주문 3건의 OrderPlaced를 두 방식으로 보낸다. 방식 1 이벤트 알림은 주문 번호만 보내고 소비자(배송·메일)가 주문 서비스에 되묻는다. 방식 2 상태를 실은 이벤트는 필요한 값까지 실어 보내고 소비자가 사본을 둔다. `sourcing.py`는 이벤트 3개를 다시 적용해 상태를 만드는 이벤트 소싱 맛보기다. 파이썬 표준 라이브러리만 쓴다.

| 파일 | 역할 |
|---|---|
| `bookshop.py` | 주문 서비스(되묻기 호출 수 세기), 두 방식의 이벤트, 소비자 |
| `sourcing.py` | 이벤트 3개 되감기(replay) |
| `demo.py` | 호출 수·사본 수·주문 서비스가 멈췄을 때 비교 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/coupon.py   # 연습 문제 풀이
