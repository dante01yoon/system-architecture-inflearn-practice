# 올바른 일 하기 예제: 데이터 최소화 · 가명 · crypto-shredding (파이썬 표준 라이브러리만)

온라인 서점의 주문 이벤트에서 개인정보를 다루는 두 가지 기법을 본다.

| 파일 | 역할 |
|---|---|
| `privacy.py` | 목적별로 필요한 칸만 남기기(`minimize`), 손님 아이디를 HMAC-SHA256 가명으로(`pseudonym`) |
| `shred.py` | 손님마다 키 하나로 이름·주소를 암호화해 로그에 적고, 탈퇴하면 그 키만 버리기 |
| `demo.py` | `1` 최소화 + 가명 · `2` 한 손님 지우기 |
| `solutions/` | 연습 문제 풀이 |

```bash
python3 demo.py 1
python3 demo.py 2
python3 -m unittest
```

주의
- `shred.py`의 `toy_encrypt`는 SHA-256으로 만든 키 흐름을 XOR하는 **장난감**이다. 원리를 보여 주려는 것이고 실제 서비스에 쓰면 안 된다. 실제로는 AES-GCM 같은 검증된 암호 라이브러리와 키 관리 서비스(KMS)를 쓴다.
- 가명은 여전히 개인정보다(GDPR 전문 26, 개인정보 보호법 2조 1호 다목 「가명정보」). 키를 지운 뒤에도 가명으로 두 주문이 같은 손님이라는 건 남는다.
- 키 저장소의 백업, 캐시, 웨어하우스, 로그 사본에 평문이 남아 있으면 키를 지워도 지운 게 아니다.
- 이 예제는 법률 자문이 아니다. 실제 서비스는 법무·개인정보 담당과 확인한다.
