# eda-log — 큐와 로그, 전달 보장, 멱등 소비자

서점 주문 메시지 3개(DDIA 1권씩, 재고 10권)로 큐와 로그를 비교한다. 파이썬 표준 라이브러리만 쓴다.

| 파일 | 역할 |
|---|---|
| `mq.py` | 메시지 큐: ack하면 지우고, ack 전에 소비자가 죽으면 다시 보낸다 |
| `log.py` | 로그: 파일 끝에 붙이기만 하고, 소비자마다 오프셋을 따로 적는다 |
| `consumer.py` | 재고 소비자(그냥 빼기)와 멱등 소비자(처리한 번호 표 + 같은 트랜잭션) |
| `demo.py` | 1 최대 한 번(잃음) 2 최소 한 번(두 번 뺌) 3 멱등 소비자 4 로그 다시 읽기 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/log_crash.py   # 연습 문제 풀이

## 연습 문제

로그 소비자가 재고를 뺀 뒤, 오프셋을 저장하기 전에 죽었습니다. 다시 켜지면 무슨 일이 생기고, 어떻게 막을까요?
