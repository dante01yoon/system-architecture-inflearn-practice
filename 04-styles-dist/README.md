# 분산 스타일 흉내 내기 (파이썬 표준 라이브러리만)

요청 하나가 서비스 N개를 건너면 네트워크 호출이 N번 생긴다. 호출마다 지연과 실패가 조금씩 붙는다.
`sim.py`가 그 모습을 같은 시드(7)로 흉내 내서, 몇 번을 돌려도 같은 숫자가 나온다.

| 파일 | 역할 |
|---|---|
| `sim.py` | 네트워크 호출 한 번(보통 1ms 남짓, 1%는 50ms 더, 0.1%는 실패)과 요청 하나(차례로·동시에) |
| `demo.py` | 모놀리스(0번) · 서비스 기반(2번) · 마이크로서비스(5번, 동시 5번, 사슬 10번) 비교표 |

```bash
python3 demo.py
python3 -m unittest
```

숫자는 가정한 값(sim.py 맨 위)에서 나온 흉내다. 실제 서비스의 지연은 직접 재야 한다.
