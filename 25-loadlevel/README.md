# loadlevel — 큐로 폭주 요청 받아 내기

반짝 할인 모형(`sim.py`, seed 고정): 10초 동안 주문 2,000건이 초당 100건을 처리하는 DB로 간다. 일꾼 4명 × 한 건 0.04초 = 초당 100건. 시간은 실제로 흐르지 않고 시작·끝 시각만 계산한다. `simulate(limit)`의 limit이 줄에 설 수 있는 최대 건수: 0 = 큐 없이 바로 DB(빈자리가 없으면 오류), None = 끝없는 큐, 300 = Little의 법칙(100건/초 × 3초)으로 정한 한도와 부하 차단. 표준 라이브러리만 쓴다.

    python3 demo.py
    python3 -m unittest
    python3 solutions/one_second.py   # 연습 문제 풀이(최대 1초 대기)

모형의 단순화: 큐 없는 경우는 「빈 DB 자리가 없으면 바로 오류」로만 셌다. 실제 과부하에서는 DB가 느려져 타임아웃까지 붙잡히는 일이 더해져 보통 더 나쁘다.
