# scale — 서버 한 대에서 백만 명까지

칸을 하나씩 더할 때 몇 명까지 버티는지 계산하는 모형(`sim.py`). 칸마다 버티는 양(대수 × 코어 × 1,000밀리초, 디스크 용량)을
사용자 한 명이 가장 몰릴 때 주는 일로 나눠, 가장 적은 칸을 병목으로 본다. 숫자는 모두 설명을 위해 정한 가정이다:
한 명이 하루에 페이지 40번 · 쓰기 2번 · 페이지마다 정적 파일 10개, 최대 = 평균 × 3, 요청마다 쓰는 시간(`MS`), 서버 한 대 코어 4개 ·
디스크 2 TB, 한 명이 쌓는 데이터 2.5 MB. 큐 뒤 작업자는 하루 평균 속도로만 꺼낸다고 본다. 표준 라이브러리만 쓴다.

    python3 demo.py 1   # 앞 네 단계(서버 한 대 → 읽기 복제본)
    python3 demo.py 2   # 뒤 네 단계(캐시 → 샤드)
    python3 -m unittest
    python3 solutions/next.py   # 연습 문제 풀이
