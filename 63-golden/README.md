# Four Golden Signals 예제: 서점 요청 로그 1시간 (파이썬 표준 라이브러리만)

seed 고정으로 서점 요청 로그 60분(분당 약 2,000건)을 만든다. 26~29분 DB가 조금씩 느려지고(중앙값 80→330ms), 30~39분 DB 느림 장애(느린 성공·1초 뒤 실패·빈 결과),
40~44분 DB 연결 끊김(대부분 곧바로 500), 45분부터 회복한다. 로그와 장애 모양은 가정이다.

| 파일 | 역할 |
|---|---|
| `log.py` | `minute`(분마다 요청), `hour`(60분) |
| `signals.py` | `signals`(지연 p99 성공·실패, 트래픽, 오류 = 명시·암묵·정책, 포화 = DB 풀 사용률, 리틀의 법칙), `pages`(증상 알림) |
| `demo.py` | `1` 대시보드와 알림, `2` 실패 지연을 나눠 봐야 하는 이유 |
| `solutions/ticket.py` | 연습 문제 풀이 |

```bash
python3 demo.py 1
python3 demo.py 2
python3 -m unittest
```
