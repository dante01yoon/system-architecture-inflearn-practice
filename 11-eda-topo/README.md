# eda-topo — 브로커 대 미디에이터, Pub/Sub, Dead Letter Channel

같은 서점 주문 흐름(재고 → 결제 → 알림·매출 집계)을 두 토폴로지로 돌린다. 파이썬 표준 라이브러리만 쓴다.

| 파일 | 역할 |
|---|---|
| `broker.py` | 토픽·구독자, 구독자마다 한 부씩(Pub/Sub), 3번 실패하면 DLQ |
| `mediator.py` | 단계 목록을 순서대로 부르고, 실패하면 끝낸 단계를 거꾸로 되돌리는 지휘자 |
| `shop.py` | 재고·결제·알림 서비스(브로커용 처리기와 미디에이터용 단계) |
| `demo.py` | 1 브로커 흐름 2 미디에이터 흐름 3 카드 거절 4 독이 든 메시지 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/compensate.py   # 연습 문제 풀이

## 연습 문제

브로커 토폴로지에서 카드가 거절되면 잡아 둔 재고가 그대로 남습니다. 지휘자 없이 재고를 되돌리려면 무엇을 더해야 할까요? (힌트: 실패도 이벤트로)
