# ddia-batch — 배치 처리: 파이프라인, 맵리듀스, 정렬-병합 조인 (파이썬 표준 라이브러리만)

DDIA 2판 11장 「Batch Processing」에서 다루는 주제를 온라인 서점 예제로 돌려 본다.

| 파일 | 역할 |
|---|---|
| `batch.py` | 접근 로그·주문 만들기(seed 고정), 유닉스식 파이프라인(제너레이터 단계), 맵리듀스(map → shuffle → reduce, 한 프로세스 안에서 차례로 흉내), 정렬-병합 조인, 일별 판매표(임시 파일 → 이름 바꾸기) |
| `demo.py` | `1` 가장 많이 본 책 다섯 권을 두 방식으로, `2` 일별 판매표를 만들고 중간에 죽은 뒤 다시 돌려도 같은 파일인지 |
| `solutions/by_hour.py` | 연습 문제 풀이 |

```bash
python3 demo.py 1
python3 demo.py 2
python3 -m unittest
```

## 무엇이 진짜이고 무엇이 흉내인가

- 맵리듀스의 「매퍼 4개·리듀서 2개」는 한 프로세스 안에서 차례로 돈다. 진짜 클러스터라면 각 매퍼가 분산 파일 시스템의 다른 블록을 다른 컴퓨터에서 읽고, 셔플은 네트워크로 오간다. 나누는 규칙(키의 해시 % 리듀서 수)과 「같은 키는 같은 리듀서로」는 같다.
- 입력 파일은 읽기만 한다. 출력은 임시 파일에 다 쓴 뒤 이름을 바꾸므로, 중간에 죽어도 반쯤 쓴 결과가 남지 않고 처음부터 다시 돌리면 된다.

## 연습 문제

`batch.py`의 셔플·리듀서는 그대로 두고 매퍼만 바꿔서, 시간대(09시, 10시 …)별 접근 수를 세 보세요.
풀이: `python3 solutions/by_hour.py`
