# sdi-notify — 알림 시스템 (파이썬 표준 라이브러리만)

알림 서비스 하나를 한 프로세스 안에 작게 만든다. 요청이 들어오면 id로 중복을 거르고, 사용자 설정(수신 거부·방해 금지 시간)과
사용자별 하루 횟수를 확인한 뒤 템플릿을 채워 채널별 큐(push·sms·email)에 넣는다. 워커는 우선순위가 높은 것부터 가짜 제공자에 보내고,
잠깐 실패하면 지수 백오프 + 지터로 다시 넣고, 4번 실패하거나 주소가 잘못되면 DLQ로 옮긴다. 시간은 실제로 기다리지 않고 계산한다.

| 파일 | 역할 |
|---|---|
| `notify.py` | `Provider`(seed로 실패가 고정된 가짜 APNs·FCM·SMS·메일), `Service.submit`(중복·설정·횟수·템플릿·큐), `Service.work`(워커·재시도·DLQ) |
| `demo.py` | `1` 알림 50개(같은 id 10건 다시 보냄)와 실패·재시도·DLQ, `2` 수신 거부와 방해 금지 시간 |
| `solutions/lost_ack.py` | 연습 풀이: 응답만 끊길 때 생기는 중복과 제공자 쪽 id 거르기 |

```bash
python3 demo.py 1
python3 demo.py 2
python3 -m unittest
```

실패율 30%, 최대 4번, 1초부터 두 배·상한 30초, 마케팅 하루 2개는 설명을 위한 가정이다. 숫자는 이 예제를 돌린 값이다.

## 연습 문제
제공자가 알림을 보내 놓고 응답만 끊기는 경우를 만들어, 재시도가 같은 알림을 두 번 보내는지 확인하고 막아 보세요. 풀이: `solutions/lost_ack.py`
