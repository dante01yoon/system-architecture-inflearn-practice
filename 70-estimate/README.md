# estimate — 규모 어림셈

서점 리뷰 기능의 QPS, 저장 용량, 대역폭을 어림하는 계산기(`est.py`). 하루 쓰기 건수 = DAU × 한 명의 하루 쓰기, 쓰기 QPS = 하루 쓰기 ÷ 86,400초,
읽기 QPS = 쓰기 QPS × 읽기:쓰기 비율, 최대 = 평균 × 배수, 저장 = 하루 쓰기 × 365 × 한 건 크기 × 보관 연수 × 복제 벌 수,
대역폭 = QPS × 한 건 크기. 단위는 1,000배씩(KB · MB · GB …), 네트워크는 × 8 해서 비트로. `rough()`는 유효숫자 한 자리로 반올림한다.
숫자는 모두 가정이다: DAU 1,000만, 한 명이 하루 0.1건 쓰기, 읽기:쓰기 100:1, 보관 5년, 복제 3벌, 최대 = 평균 × 5,
리뷰 한 건 글 1 KB · 사진 500 KB × 2장, 읽기 한 번 = 리뷰 하나를 통째로 받기. 표준 라이브러리만 쓴다.

    python3 demo.py 2   # 사진 두 장을 붙인 리뷰
