# saga — Saga ① 1987년 논문을 파이썬으로

서점 주문 네 단계(주문 → 결제 → 재고 → 배송)를 단계마다 짧은 트랜잭션 T로 나누고, 단계마다 보상 C를 짝지어 둔다. 파이썬 표준 라이브러리(sqlite3)만 쓴다.

| 파일 | 역할 |
|---|---|
| `saga.py` | Saga 실행기. 실패하면 끝낸 단계의 보상을 거꾸로 부르고, 일어난 순서를 기록 |
| `shop.py` | 네 단계 T1~T4와 보상 C1~C3(지우지 않고 상태를 바꾸거나 그만큼 더한다) |
| `demo.py` | 1 긴 트랜잭션의 잠금 2 Saga 성공 3 3단계 실패와 거꾸로 보상, 중간 상태가 보임 |

    python3 demo.py
    python3 -m unittest
    python3 solutions/overwrite.py   # 연습 문제 풀이
