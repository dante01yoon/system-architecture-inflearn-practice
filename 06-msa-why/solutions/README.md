# 연습 문제 풀이

문제: catalog를 내린 동안, order가 한 번도 값을 본 적 없는 책(Release It!)을 주문하면 어떻게 될까? 왜 그럴까?

풀이: `실패: 카탈로그 응답 없음`. order는 catalog를 동기 호출로 부르고, 저장해 둔 값이 없는 책은 답을 만들 수 없다.
독립 배포가 되려면 배포 단위만 따로인 것으로는 부족하고, 상대가 잠깐 없어도 견디게(Design for failure) 만들어야 한다.
앞 수업의 말로 하면, 동기 호출은 두 서비스를 한 퀀텀으로 묶는다. `python3 solutions/check.py`로 확인.
